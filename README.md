<h1 align="center">Hachimi 八耳</h1>

<p align="center"><b>From messy thoughts to clear words.</b><br>
Local voice typing for Windows 10 / 11. Free, offline, 30 languages.</p>

When you talk, you think as you go: "um", false starts, "no wait, Tuesday". Hachimi types what you meant into whatever box your cursor is in.

| Key | What you get |
|-----|--------------|
| **F8** Clean | Fillers gone, corrections applied, loose thoughts turned into one clear paragraph. Say "make it a list" and it becomes a list. |
| **F7** Verbatim | Only fillers removed and punctuation added. Every word you said stays; the result is checked word by word against what you said. |
| **F9** Raw | Exactly what was recognized. |

- Everything runs on your PC. Your voice never leaves it, and after the models are downloaded no internet is needed.
- Free. No account, no subscription, no word limit.
- 30 languages, detected automatically. Switch languages between sentences without changing anything.
- Works best with an NVIDIA GPU (6 GB+). AMD and Intel GPUs work too, more slowly.

**This repository only holds releases and takes feedback.** Please open an [Issue](https://github.com/SenorToru/Hachimi-Releases/issues) for bugs and ideas.

The installer is not code-signed yet, so Windows SmartScreen will warn you the first time: click **More info → Run anyway**. Each release lists the installer's SHA-256 so you can check it.

## 日本語

**散らかる思考に、整う言葉を。**
Windows 10 / 11 用のローカル音声入力です。無料・オフライン・30 言語対応。

話すときは考えながら話すので、「えっと」や言い直しが混ざります。八耳はそれを整えて、カーソルのある入力欄にそのまま貼り付けます。

- **F8 整形**：言いよどみを消し、言い直しを反映して、まとまった文章にします。「箇条書きにして」と言えば箇条書きに。
- **F7 逐語**：言いよどみだけを消して句読点を付けます。話した言葉は一字も変えません。
- **F9 原文**：認識したそのままです。

音声はすべてお使いの PC の中で処理され、外には出ません。不具合やご要望は [Issue](https://github.com/SenorToru/Hachimi-Releases/issues) へどうぞ。

## 简体中文

**碎语成章，出口成理。**
Windows 10 / 11 本机语音输入。免费、离线、30 种语言。

- **F8 整理**：删掉口头禅，按你的改口只留最后的意思，理成通顺的一段话。
- **F7 逐字**：只删口头禅、补标点，你说的话一字不改。
- **F9 原文**：认出什么贴什么。

声音和文字都只在你的电脑上处理。问题和建议请开 [Issue](https://github.com/SenorToru/Hachimi-Releases/issues)。中国大陆用户请到 [cn.hachimi.meme](https://cn.hachimi.meme) 下载。

## 繁體中文

**碎語成章，出口成理。**
Windows 10 / 11 本機語音輸入。免費、離線、30 種語言。

- **F8 整理**：刪掉口頭禪，依你的改口只留最後的意思，整理成通順的一段話。
- **F7 逐字**：只刪口頭禪、補標點，你說的話一字不改。
- **F9 原文**：辨識出什麼就貼什麼。

聲音和文字都只在你的電腦上處理。問題和建議請開 [Issue](https://github.com/SenorToru/Hachimi-Releases/issues)。
